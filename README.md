# Hyperion — versiones

Instaladores de **Hyperion**, explorador de archivos para Windows.

Descarga el instalador (`Hyperion_X.Y.Z_x64-setup.exe`) de la [última versión](../../releases/latest).
Una vez instalado, Hyperion se actualiza solo desde aquí (Ajustes → Actualizaciones, canal Estable o Beta).

Cada instalador está firmado; Hyperion rechaza cualquier actualización cuya firma no coincida.

Hyperion incluye UnRAR (© Alexander Roshal) bajo su propia licencia, que se instala junto al programa.
